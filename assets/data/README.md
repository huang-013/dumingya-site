# 杜冥鸦 · 作品集 —— 内容维护指南

本目录包含所有内容数据。每个文件对应网站一个区块，**只改数据，不需要碰 HTML/CSS/JS**。

## 📁 文件结构

```
assets/
├── data/                ← 全部作品数据（你只需要改这里）
│   ├── profile.js       首屏：本人资料 / 代表角色 / 照片集
│   ├── games.js         游戏角色配音（按年份分组）
│   ├── animations.js    动画 / PV 配音
│   ├── dramas.js        商业广播剧（按官宣年份分组）
│   ├── webdramas.js     网配广播剧（数量最多，470 期）
│   ├── earlyworks.js    早期网配介绍
│   ├── socials.js       社交平台
│   ├── events.js        线下活动行程
│   ├── music.js         音乐作品
│   └── footer.js        页脚文案
├── img/                 封面 / 立绘 / 头像图片
├── audio/               角色语音 / 音乐
├── css/                 样式表（一般无需修改）
└── js/                  渲染逻辑（一般无需修改）
```

## ✏️ 怎么加一条作品？

**举例：加一部新的商业广播剧**

1. 打开 `dramas.js`
2. 找到对应年份的分组（如 `"year": "2024"`），把新作品追加到 `items` 数组
3. 字段说明（每个文件顶部都有完整注释）：

```js
{
  "title": "剧名",
  "season": "第一季",
  "role": "角色名",
  "castType": "主役",           // 主役/协役/客串/报幕 → 决定标签颜色
  "platform": "饭角",            // 饭角/漫播/听姬
  "announceDate": "2024.06.01",
  "endDate": "2024.08.01",      // 填 "连载中" 自动加绿色标签
  "cover": "assets/img/xxx.jpg", // 选填，不填显示渐变占位图
  "audio": "assets/audio/xxx.mp3", // 选填，不填不显示播放按钮
  "link": "https://..."          // 选填，填了就整张卡片可点击
}
```

4. 保存文件，刷新浏览器即可看到。

**举例：加一首音乐**

打开 `music.js`，在数组末尾追加：

```js
{
  "title": "歌名",
  "year": "2024",
  "cover": "assets/img/xxx.jpg",  // 选填
  "remark": "备注：合作方 / 出处 / 角色歌"
}
```

## 🎨 封面 / 音频 / 头像放在哪？

| 类型 | 目录 | 推荐比例 / 格式 |
|---|---|---|
| 角色立绘 | `assets/img/` | 竖版 4:5，webp / jpg / png |
| 头像（切换条） | `assets/img/` | 正方形，webp / jpg |
| 背景场景图 | `assets/img/` | 横版 16:9 |
| 作品封面 | `assets/img/` | 横版 16:9 或正方形 |
| 角色语音 | `assets/audio/` | mp3 / wav / ogg |

## ⚠️ 修改注意事项

1. **字符串必须用英文双引号 `"`** 包裹，字符串内部不能再出现裸双引号
2. **最后一项后面不要加逗号**（JSON 不允许尾逗号；多写一个逗号整页会空白）
3. **数组顺序 = 页面显示顺序**。年份分组请保持「最新年份在最前面」
4. 改之前先复制一份文件备份；写错会导致整页空白
5. 编辑器推荐用 **VS Code**（自带 JSON / JS 语法检查）

## 🧪 改完没生效？

1. 浏览器要按 **Ctrl/Cmd + Shift + R 强制刷新**（清缓存）
2. F12 打开 Console，看有没有红色报错
3. 大概率是逗号 / 引号问题，对照文件顶部注释检查字段名

## ➕ 新增一种内容类型？

如果未来想加新分类（如「有声书」「直播回放」），需要：
1. 在 `assets/data/` 下新建一个 `.js` 文件
2. 在 `index.html` 里加一行 `<script src="..."></script>`（放在 app.js 之前）
3. 在 `assets/js/app.js` 里写一个 `renderXxx()` 函数把数据渲染到对应区块
4. 在 `assets/css/main.css` 里给新区块加样式

如果你不想改代码，把数据加在 `animations.js` 或 `events.js` 里也可以。
